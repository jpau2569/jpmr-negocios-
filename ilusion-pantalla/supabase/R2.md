# Cloudflare R2 — puesta en marcha

Un único bucket **privado** (`ilusion-videos`). Nada se sirve por URL pública: gratis y premium salen por URL firmada de 10 min, así el control de acceso es uniforme y los premium no se pueden listar ni adivinar.

## Pasos (una vez)
1. Cloudflare → R2 → crear bucket `ilusion-videos` (jurisdicción UE si el plan lo permite). **No** activar acceso público ni dominio `r2.dev`.
2. R2 → *Manage API tokens* → token S3 con permiso **Object Read & Write** limitado a ese bucket. Guardar *Access Key ID*, *Secret* y *Account ID*.
3. Secretos de las funciones (nunca en la app ni en git):
   ```
   supabase secrets set R2_ACCOUNT_ID=... R2_ACCESS_KEY_ID=... R2_SECRET_ACCESS_KEY=... R2_BUCKET=ilusion-videos
   supabase secrets set CORS_ORIGIN=https://panel.tu-dominio.com
   supabase functions deploy wallpaper-url admin-subida
   ```
4. CORS del bucket (solo para que el **panel** suba con PUT): origen del panel, método `PUT`, cabecera `Content-Type`.
5. Regla de ciclo de vida: abortar subidas multiparte incompletas a los 7 días.

## Convención de claves
`videos/<slug>/<calidad>.mp4` · `imagenes/<slug>/<thumb|poster|preview>.<ext>`. Un registro en `wallpaper_archivos` por cada vídeo (`storage_bucket='ilusion-videos'`, `storage_path=<clave>`).

## Flujo
- **Descarga**: app → `wallpaper-url {wallpaper_id, calidad, hevc, fps}` → URL firmada → descarga a archivo privado de la app.
- **Subida (panel)**: panel → `admin-subida` (solo admin/editor) → PUT directo a R2 → el panel inserta la fila en `wallpaper_archivos`.

## Límites y pendientes conocidos
- Las miniaturas/posters que muestra el catálogo deben ser públicas y baratas: en la Fase 2 se sirven desde un dominio propio con caché de Cloudflare (otro bucket público *solo* de imágenes) o desde Supabase Storage. Hasta entonces `url_thumbnail` apunta a donde se decida.
- **No probado contra R2 real**: la firma está validada con el vector oficial de AWS y las reglas con tests; falta una prueba con credenciales reales.
- Las funciones están escritas para Deno pero no se han ejecutado aquí (no hay Deno instalado).
