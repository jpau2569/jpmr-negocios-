# Skill: Documento de oficina

## Cuándo usarla
Pau pide «hazme una carta», «un escrito para…», «un informe para el cliente», «una autorización», «un comunicado», «una nota de encargo», o cualquier documento para imprimir, firmar o enviar.

## Método
1. **Lo mínimo para empezar.** Quién lo firma, a quién va, qué tiene que conseguir el documento y la fecha. Si falta algo imprescindible, pregúntalo en una sola tanda (máximo 3 preguntas). Lo demás se rellena con [corchetes] visibles para completar.
2. **Nada inventado.** Ni NIF, ni direcciones, ni referencias catastrales, ni artículos de ley que no hayas comprobado. Si citas normativa, verifícala con buscar_web (o con NURIA mediante consultar_equipo) y pon la fuente.
3. **Estructura según el tipo.**
   - Carta: remitente, fecha y lugar, destinatario, asunto, cuerpo y firma.
   - Informe: título, resumen en 3 líneas, desarrollo por apartados, conclusiones y siguiente paso.
   - Autorización o certificado: quién autoriza o certifica, qué, para qué, con qué límites y hasta cuándo, firma.
4. **Documentos con efectos legales** (contratos, autorizaciones, reclamaciones): márcalos «BORRADOR — revisar con gestor o abogado» y recomienda la revisión. Si el documento es importante, pide a NICER que lo revise (consultar_equipo) antes de entregarlo.

## Entrega estándar
- Un único bloque ```html con un documento completo (`<!doctype html>`). El chat ofrece el botón «Descargar HTML» → abrir → Ctrl+P → «Guardar como PDF». Para Word: abrir el HTML con Word y guardar como .docx.
- CSS embebido: A4 (`@page { size: A4; margin: 20mm }`), letra serif para títulos y sans para el cuerpo, azul marino #10203a y dorado #c9a227, cabecera «Asesoría Castresana · Gestión Inmobiliaria · Oviedo · Tel. 985 210 468 · asesoriacastresana.com».
- Bajo el HTML, una línea con lo que queda entre [corchetes] por completar.

## Norma
Claro, educado y breve. Una idea por párrafo. Nada de relleno ni de fórmulas antiguas («sin otro particular»).
